# 🖥️ Sistemi Operativi e Laboratorio

Repository dedicato al corso di **Sistemi Operativi e Laboratorio** del corso di laurea triennale in **Informatica** presso l'**Università degli Studi di Ferrara**.

Qui raccolgo gli esercizi, le esercitazioni di laboratorio e i progetti sviluppati durante il corso, con un focus sulla **gestione dei processi in ambiente UNIX**.

---

## 📚 Argomenti trattati

- Creazione e gestione dei processi (`fork`, `exec`, `wait`, `exit`)
- Comunicazione tra processi (pipe, FIFO, segnali)
- Thread e programmazione concorrente
- Sincronizzazione (semafori, mutex, monitor)
- Gestione dei file e dell'I/O in UNIX
- Concorrenza e processi in Java (`Thread`, `Runnable`, `synchronized`, `ProcessBuilder`)

> L'elenco verrà aggiornato man mano che il corso procede.

---

## 🛠️ Linguaggi e strumenti

| Linguaggio | Utilizzo |
|-----------|----------|
| **C** | Programmazione di sistema su UNIX (chiamate di sistema, processi, IPC) |
| **Java** | Programmazione concorrente e gestione di thread/processi |

**Strumenti consigliati:** `gcc`, `make`, `gdb`, JDK 17+, ambiente Linux/macOS o WSL.

---


## ▶️ Come compilare ed eseguire

### Programmi in C

```bash
gcc -Wall -o programma programma.c
./programma
```

### Programmi in Java

```bash
javac Programma.java
java Programma
```
